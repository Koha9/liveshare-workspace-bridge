# v0.2.1 サンドボックス IPC 検証

[English](VALIDATION-v0.2.1.md) | [简体中文](VALIDATION-v0.2.1.zh-CN.md) | [繁體中文](VALIDATION-v0.2.1.zh-TW.md) | **日本語**


確認済みの Windows ユーザー境界と検出エラー隠蔽を修復するパッチです。保留の大容量ダウンロードや、別問題の Computer Use 初期化は修復対象ではありません。

| チェック | 結果 |
|---|---|
| ローカル回帰 | 44 件成功、Windows でスキップなし。構文、パッケージ／ソース、SHA-256 照合成功。 |
| 実サンドボックス、owner-only | CodexSandboxOffline/Online とも送信前拒否。EPERM、requestSent:false。 |
| 実サンドボックス、明示信頼 | 両アカウントで同じ Windows セッションの Unicode 往復成功。 |
| インストール済み拡張、信頼無効 | access_denied／discovery_access_denied と各拒否を報告し、[] に隠しません。 |
| インストール済み拡張、信頼有効 | 対象テストプロジェクトを検出。無関係の古い記録／旧ウィンドウは partial として明示。 |
| 実 Live Share、両アカウント | 各 2 所有ファイルの作成／保存、バージョン保護付き 2 ファイル編集、文書と明示プロバイダーテキスト照合、古いバージョン拒否、後片付けに成功。 |
| 操作権限 | 読み取り、agent 全体、Host 無効を実サンドボックスで確認。Host コマンド送信なし。 |
| ライフサイクル／フレーム | 信頼変更はブリッジのみ再起動し旧 ID を無効化。連続応答、過大で改行なしの要求、不正 UTF-8 を検証し、拒否データを処理へ渡しません。 |
| 後片付け | 両ディレクトリ不在、dirty 文書なし。操作設定を復元し同時ユーザー変更なし。ユーザーの明示選択により信頼設定は有効で保持。 |

テスト用 Live Share を使用し、本番は操作していません。詳細記録は Git 対象外のローカル証拠のみです。公開版は owner-only が既定で、明示信頼は同じ Windows セッションの該当アカウント全プロセスに適用されます。一つのタスクだけの認可でも Codex ファイルシステムサンドボックスでもありません。[IPC の安全性](IPC-SECURITY.ja.md)を参照してください。

セッションロジック／DACL 検査は実別セッションや別ホストの侵入試験ではありません。MXC や全言語／全プロジェクトは再検証していません。v0.2 Host 観測は過去の証拠で、本検証は Host ビルド／テスト、生バイト、ダウンロードの新たな受け入れ完了を意味しません。
