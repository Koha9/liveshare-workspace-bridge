# v0.2.1 沙箱 IPC 验收

[English](VALIDATION-v0.2.1.md) | **简体中文** | [繁體中文](VALIDATION-v0.2.1.zh-TW.md) | [日本語](VALIDATION-v0.2.1.ja.md)


本补丁修复已确认的 Windows 用户身份边界和发现错误隐藏问题，不修改延期的大文件下载能力，也不修复独立的 Computer Use 沙箱初始化问题。

| 检查 | 结果 |
|---|---|
| 本地回归 | 44 项测试通过，Windows 上无跳过；语法、包／源码和 SHA-256 校验通过。 |
| 真实沙箱、owner-only | CodexSandboxOffline 和 CodexSandboxOnline 均在发送前被拒绝：EPERM、requestSent:false。 |
| 真实沙箱、明确开启信任 | 两账户均完成同会话可信管道的 Unicode 请求往返。 |
| 已安装扩展、信任关闭 | 发现返回 access_denied／discovery_access_denied 和逐项拒绝，不再伪装为 []。 |
| 已安装扩展、信任开启 | 正确测试项目可被发现；无关过期记录／旧窗口明确报告为 partial。 |
| 已安装 Live Share、两个沙箱身份 | 各新建并保存两个自有文本文件，完成受版本保护的两文件编辑，检查文档和显式提供者文本，拒绝过期版本，并清理目录。 |
| 沙箱内操作权限 | 读取权限、agent 总开关、Host 访问关闭均生效，没有派发 Host 命令。 |
| 生命周期与帧 | 信任变更只重启桥接、撤销旧实例；快速连续响应、超限无换行请求和非法 UTF-8 通过测试，被拒绝帧未进入操作分发。 |
| 清理 | 两个测试目录均已不存在，无 dirty 文档，临时操作设置已恢复，无并发用户改动；新信任开关按用户明确选择保留开启。 |

使用的是测试 Live Share 会话，不是生产环境。详细回执仅保留在忽略的本机证据中，不发布用户／Host 数据。发布默认仍 owner-only，沙箱接入需要用户明确授权。这信任同一 Windows 会话内这些账户的全部进程，不限单个任务，也不执行 Codex 文件系统沙箱限制。见 [IPC 安全](IPC-SECURITY.zh-CN.md)。

会话逻辑和 DACL 测试不等于真实第二会话／远程主机渗透测试。未重新验证 MXC 或所有语言／项目组合。v0.2 的 Host 功能记录仍是历史证据；本次不新增 Host 构建测试、原始字节或下载验收结论。
