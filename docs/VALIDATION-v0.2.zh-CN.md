## 延后能力与条件

- 大文件下载在 Host 派发前以 `feature_unavailable` 阻止；不循环字节读取或发明新传输。请用户提供可访问副本和路径。
- 递归删除、跨文件原子落盘按约定不提供；请用户协助，或在适用时明确接受逐文件保存。
- Host 搜索只覆盖已保存文件，不合并或保存 dirty 缓冲区；快照完整性未知。
- Host 修改可能早于 Guest 刷新；保留缓冲区，报告 `editor_refresh_pending/external_change_dirty_document`，必要时请用户解决或重新打开。
- 目录复制必须新建目标，失败可能留部分结果；补丁换行受 Host Git 配置影响。
- Host 功能目前需要 Windows Host PowerShell 与已连接的共享 RW 终端。终端权限默认关闭；操作权限不是任意 Host 命令的操作系统沙箱。
- 撤销权限阻止新工作，不撤销已派发效果；未知结果的已发送修改不自动重放。

skill 对每个未解决步骤请求一次用户协助，在回复前暂停依赖工作，并区分用户协助完成和插件实际执行。构建与仓库修改不隐含发布、暂存、commit 或 push。
