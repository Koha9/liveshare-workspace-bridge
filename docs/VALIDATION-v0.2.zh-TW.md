## 自動檢查

- Windows 驗證環境中 37 項 Node 測試通過，無跳過。
- 執行階段和規范 skill 客戶端的 Node 語法檢查通過，skill 前置中繼資料和布局驗證通過。
- VSIX 與 skill ZIP 通過精確成員／原始碼和 SHA-256 校驗；skill 包包含 API 與 recovery 引用。
- 覆蓋當前使用者具名管道、生命周期、編輯預檢、目標儲存、部分儲存失敗、權限、補丁路徑、過期緩衝區保護、語言重新命名、Host 位元組基礎操作、有界輸出、退出碼、超時和取消。

## 實際觀察

實際修改均使用自有唯一測試目錄，不編輯業務原始碼；詳細回報紀錄僅保留本機。臨時權限設定已復原，測試目錄已確認不存在。

| 能力 | 證據與結果 |
|---|---|
| Host 繫結 | 自有 bootstrap 檔案驗證共用 RW PowerShell；不選擇普通 Guest 終端，缺失終端明確報錯。 |
| 已儲存檔案搜尋與枚舉 | Host rg 回傳正向匹配、無匹配退出碼 1、新建路徑；完整性仍受輸出／結果限制。 |
| Host 任務 | 保留原生命令退出碼 7 和 PowerShell 失敗碼 1；stdout/stderr 各限制 65,536 字元並標記截斷；自有處理程序超時和取消通過。 |
| 位元組與複製 | 4,096 位元組二進位往返、檔案複製、目錄複製和受保護覆蓋通過 Host SHA-256 對比。 |
| 文字補丁 | Git 檢查和應用通過；測試中 Host Git 輸出 CRLF，文字等價通過。Guest 模型可能保持 dirty／過期，擴充套件明確拒絕而非覆蓋。 |
| 語言工具 | JavaScript 測試中 4 個引用位置、兩檔案重新命名儲存和格式化通過；其他專案依賴自身提供者。 |
| 大檔案上傳 | 1,100,123 位元組上傳通過分塊確認與 SHA-256。 |
| 權限 | 即時阻止文字讀取、原始命令繞過、全部終端功能和全部 agent 操作；測試設定復原。 |
| 大檔案下載 | 多次實際傳輸失敗，一次約 450 KB 後超時，終端隨後不回應唯讀復原握手；根因未解決。 |

**沒有一次全部通過的 Host 端到端測試**：下載失敗中斷過整套測試。表中是分別觀察到的分項結果。之後加入的輸出節流和超時診斷通過本機檢查，但未證明解決持續終端輸出；不能把本機下載基礎操作測試當作實際下載驗收。

## 延後能力與條件

- 大檔案下載在 Host 派發前以 `feature_unavailable` 阻止；不迴圈位元組讀取或發明新傳輸。請使用者提供可存取副本和路徑。
- 遞歸刪除、跨檔案原子落盤按約定不提供；請使用者協助，或在適用時明確接受逐檔案儲存。
- Host 搜尋只覆蓋已儲存檔案，不合併或儲存 dirty 緩衝區；快照完整性未知。
- Host 修改可能早於 Guest 刷新；保留緩衝區，報告 `editor_refresh_pending/external_change_dirty_document`，必要時請使用者解決或重新打開。
- 目錄複製必須新建目標，失敗可能留部分結果；補丁換行受 Host Git 組態影響。
- Host 功能目前需要 Windows Host PowerShell 與已連線的共用 RW 終端。終端權限預設關閉；操作權限不是任意 Host 命令的作業系統沙箱。
- 撤銷權限阻止新工作，不撤銷已派發效果；未知結果的已發送修改不自動重送。

skill 對每個未解決步驟請求一次使用者協助，在回覆前暫停依賴工作，並區分使用者協助完成和擴充套件實際執行。建置與倉庫修改不隱含發佈、暫存、commit 或 push。
