# v0.2.1 沙箱 IPC 驗收

[English](VALIDATION-v0.2.1.md) | [简体中文](VALIDATION-v0.2.1.zh-CN.md) | **繁體中文** | [日本語](VALIDATION-v0.2.1.ja.md)


本修補修復已確認的 Windows 使用者身分邊界與探索錯誤隱藏，不改變延後的大檔案下載能力，也不修復獨立的 Computer Use 沙箱初始化問題。

| 檢查 | 結果 |
|---|---|
| 本機回歸 | 44 項測試通過，Windows 無跳過；語法、套件／原始碼及 SHA-256 驗證通過。 |
| 真實沙箱、owner-only | CodexSandboxOffline、CodexSandboxOnline 都在傳送前遭拒：EPERM、requestSent:false。 |
| 真實沙箱、明確開啟信任 | 兩帳戶完成同工作階段可信管道的 Unicode 往返。 |
| 已安裝擴充套件、信任關閉 | 探索回傳 access_denied／discovery_access_denied 和各項拒絕，不偽裝為 []。 |
| 已安裝擴充套件、信任開啟 | 正確測試專案可探索；無關過期記錄／舊視窗明確報告 partial。 |
| 已安裝 Live Share、兩沙箱身分 | 各建立並儲存兩個自有文字檔，完成受版本保護的兩檔編輯，核對文件及明確提供者文字、拒絕過期版本並清理目錄。 |
| 沙箱操作權限 | 讀取權限、agent 總開關與 Host 存取關閉均生效，沒有派發 Host 命令。 |
| 生命週期與訊框 | 信任變更只重啟橋接並撤銷舊執行個體；快速連續回應、超限無換行及非法 UTF-8 測試通過，拒絕訊框未進入分發。 |
| 清理 | 兩測試目錄不存在，無 dirty 文件，暫時操作設定已復原且無同時使用者變更；信任開關依使用者明確選擇保留開啟。 |

使用測試 Live Share，未操作生產。詳細回報紀錄只保留於忽略的本機證據，不公開使用者／Host 資料。發佈預設仍 owner-only，沙箱接入須明確授權，信任同一 Windows 工作階段中這些帳戶的全部處理程序，不限單一工作，也不執行 Codex 檔案系統沙箱限制。見 [IPC 安全](IPC-SECURITY.zh-TW.md)。

工作階段邏輯與 DACL 測試不等於真實第二工作階段／遠端滲透測試。未重驗 MXC 或所有語言／專案組合。v0.2 Host 記錄仍屬歷史證據，本次不新增 Host 建置測試、原始位元組或下載驗收結論。
