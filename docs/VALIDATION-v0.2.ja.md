拡張と skill は同じバージョンで管理します。この記録はローカル自動チェックと、実 Windows Live Share Guest/Host の観測を区別します。token、Host 生パス、業務プロジェクト内容は含めません。

## 自動チェック

- Windows 検証環境で Node テスト 37 件成功、スキップなし。
- ランタイムと正規 skill クライアントの構文チェック、skill メタデータ／構成検証に成功。
- VSIX と skill ZIP は正確なメンバー／ソースと SHA-256 照合に成功。skill に API と recovery 参照を含みます。
- 現在ユーザー専用パイプ、ライフサイクル、編集事前検証、対象保存、部分保存失敗、権限、パッチパス、古いバッファー保護、名前変更、Host バイト基本処理、上限付き出力、終了コード、タイムアウト、キャンセルを確認します。

## 実測結果

実変更は一意の所有テストディレクトリだけで行い、業務ソースを編集しませんでした。詳細記録はローカル専用です。一時権限を復元し、テストディレクトリの不在を確認しました。

**Host の全項目を一回で通過したエンドツーエンドテストはありません。** ダウンロード失敗が全体実行を中断しました。表は別々に観測した結果です。後から加えた出力ペーシングと診断はローカル検証済みですが、持続出力の修復は未確認です。ローカル転送基本処理の成功を実ダウンロード受け入れ完了としません。

## 保留と条件付き動作

- 大容量ダウンロードは Host 送信前に `feature_unavailable` で拒否します。小分け読み取り反復や別転送方式で迂回せず、アクセス可能なコピーとパスを依頼します。
- 再帰削除と複数ファイルの原子的保存は意図的に未提供です。手動協力、または適切な場合にファイル単位保存への明示的同意を求めます。
- Host 検索は保存済みのみで、dirty バッファーを保存／統合しません。スナップショットの完全性は不明です。
- Host 変更が Guest 更新に先行し得ます。バッファーを保持し `editor_refresh_pending/external_change_dirty_document` を報告し、必要なら解決／再オープンを依頼します。
- ディレクトリコピーは新規宛先のみで部分失敗があります。パッチ改行は Host Git 設定に従います。
- 現在は Windows Host PowerShell と接続済み共有 RW 端末が必要です。端末権限は既定無効で、任意コードの OS サンドボックスではありません。
- 権限撤回は新規作業のみ停止し、送信済み効果は戻しません。結果不明の送信済み変更を自動再送しません。

skill は未解決の手順ごとに一度協力を依頼し、返答まで依存作業を待ち、ユーザーによる完了とブリッジ操作を区別します。ビルド／ソース変更は公開、stage、commit、push を意味しません。
