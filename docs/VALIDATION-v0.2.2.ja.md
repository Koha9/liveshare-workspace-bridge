# v0.2.2 候補版の検証

[English](VALIDATION-v0.2.2.md) | [简体中文](VALIDATION-v0.2.2.zh-CN.md) | [繁體中文](VALIDATION-v0.2.2.zh-TW.md) | **日本語**


これはソース／パッケージ検証で、インストール済み v0.2.2 の本番受け入れではありません。既存 v0.2.1 WIP を保持し、インストール済み拡張、ローカル skill、User 設定は変更していません。配備／実移行は接続やウィンドウ再起動に影響するため追加承認待ちです。

| 証拠 | 結果 |
|---|---|
| ローカル一式 | Windows 53 件成功、スキップなし。構文、ビルド、skill、パッケージ検証成功。 |
| ネイティブ方針の模擬 | ownerOnly は追加選択を無視、allLocalUsers はローカル一覧だけ、selectedUsers は SID 完全一致。改名は保持、削除同名再作成は非継承、不正／グループ／外部ドメイン SID は拒否。 |
| 実ローカル API | 既存 SAM 列挙成功。選択 SID の DACL は広範グループを許可せず、二重サーバーと別セッション判定を拒否。DC 拒否は役割／方針テストで実 DC ではありません。 |
| 移行／UI モック | 旧 true は元の二 SID の selectedUsers、false は移行なし。キャッシュ SID を名前で再解決しません。明示 User が優先し、workspace/default 注入は拡大不可。取消は無変更、確定は SID を保存し terminal を変更しません。 |
| 実アカウント echo | 既存 CodexSandboxOffline/Online は ownerOnly で送信前拒否、selectedUsers で捕捉 SID により Unicode 往復成功。所有一時パイプだけで、インストール済み Live Share ではありません。 |
| 未実施 | 現環境で allLocalUsers 配備、アカウント作成／改名／削除、本番／Host コマンド、DB、マシン／ドメイン方針修復はなし。インストール済み v0.2.2 移行や Live Share 書き込み受け入れは未実施。 |

v0.2.1 の実受け入れは過去の証拠で、新版の配備後検証を代替しません。実改名、外部ドメインログイン、別 Windows セッション、リモート侵入試験は未実施です。UI はモックで、現在の VS Code に適用していません。全ローカル方針は一覧／選択の検証で、全アカウントの実ログイン検証ではありません。

ローカル配備計画には現在の旧二 SID と User 設定ハッシュを記録します。承認前後に再照合し、変化後は流用しません。初回前の削除再作成 SID を旧ブールから復元できません。承認後にインストール、必要な再読み込み、selectedUsers と正確な SID 確認、必要なら Live Share 再接続、所有テスト領域で受け入れを行います。新たな Host 権限は開きません。

後続の重点テストでも、プロセス出力が分割された Unicode アカウント名を正しく復号できました。
